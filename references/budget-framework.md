# 预算优化决策框架

## 核心逻辑

预算优化的本质：**把钱从低效系列移到高效系列**。

不是单纯削减预算，而是重新分配——让每一分钱都花在最有可能带来转化的地方。

---

## 第一步：给每个广告系列打「预算效率分」

**计算方式：**

```
预算效率分 = ROAS 指数 × 预算利用率

ROAS 指数 = 实际 ROAS / 账户平均 ROAS
预算利用率 = 实际消耗 / 设定预算
```

| 效率分区间 | 解读 | 建议 |
|-----------|------|------|
| > 1.5 | 高效，预算受限 | 增加预算 20-50% |
| 1.0 - 1.5 | 良好，可小幅优化 | 维持或小幅增加 |
| 0.5 - 1.0 | 一般，需观察 | 维持，同时优化创意/落地页 |
| < 0.5 | 低效 | 削减预算，找根因 |

---

## 第二步：识别「预算受限」的高效系列

在 Google Ads 后台，点击广告系列 → 查看「预算列」，如果出现「受限」标签：

**判断是否值得加预算：**
1. 该系列的 CPA 是否低于目标 CPA？ → 是 = 应该加
2. 该系列的 ROAS 是否高于账户均值？ → 是 = 应该加
3. 加预算后的预估增量转化是否合算？ → 参考 Google 的「预算建议」

---

## 第三步：预算迁移方案

**迁移原则：**
- 不要一次迁移超过 20%，避免系统学习期波动
- 削减预算先观察 3-5 天，确认效果再继续

**模板输出格式：**

```
## 预算优化建议

**当前总预算：** ¥XX/天
**建议调整后：** ¥XX/天（不变/增加/削减）

| 广告系列 | 当前预算 | 建议预算 | 变化 | 理由 |
|---------|---------|---------|------|------|
| 品牌词系列 | ¥XX | ¥XX | +20% | ROAS 8.5x，长期受限 |
| 竞品系列 | ¥XX | ¥XX | -30% | CPA 超目标 150% |
| 核心产品词 | ¥XX | ¥XX | +15% | 利用率92%，CPA 达标 |

**预计影响：**
- 转化量变化：+XX（预估）
- 总成本变化：+¥XX/天
- 新目标 CPA：¥XX
```

## 常见预算问题诊断

**问题1：预算消耗不完**
可能原因：搜索量不足 / 出价太低 / 质量分差导致展现少
→ 先排查原因，不要盲目加预算

**问题2：预算一早耗光**
可能原因：没设置广告展示时间 / 出价过激进 / 受众定向太窄导致 CPM 过高
→ 设置分时出价策略，或启用「标准」投放节奏

**问题3：ROAS 忽高忽低**
可能原因：转化追踪有问题 / 季节性因素 / 竞价环境波动
→ 先确认转化追踪数据准确，再做判断
