# RSA 广告文案模板与规则

## Google RSA 基本规则

| 元素 | 数量 | 字符限制 |
|------|------|---------|
| 标题 | 最多15条（最少3条） | 每条 ≤30字符 |
| 描述 | 最多4条（最少2条） | 每条 ≤90字符 |
| 展示URL路径 | 2段 | 每段 ≤15字符 |

Google 会自动测试组合，最多同时展示3条标题+2条描述。

---

## 标题写法框架（15条覆盖5个维度）

### 维度1：核心关键词（2-3条）
直接包含用户搜索词，提高相关性分数
```
示例：专业 SEO 服务
示例：企业网站优化方案
示例：[关键词插入] 解决方案
```

### 维度2：核心卖点/差异化（3-4条）
你比竞品好在哪里
```
示例：10年行业经验
示例：响应时间<2小时
示例：免费诊断，不满意退款
示例：服务500+企业客户
```

### 维度3：用户收益（2-3条）
用户用了你的产品/服务会得到什么
```
示例：流量提升3倍以上
示例：节省60%营销成本
示例：30天见效或退款
```

### 维度4：信任背书（2-3条）
为什么相信你
```
示例：Google 认证合作伙伴
示例：4.9分 · 200+真实评价
示例：Fortune 500 供应商
```

### 维度5：行动召唤（2-3条）
告诉用户下一步做什么
```
示例：立即获取免费方案
示例：今日咨询享优惠
示例：预约免费诊断
```

## 描述写法框架（4条覆盖2个角度）

### 角度1：扩展卖点（2条）
标题说不完的，在描述里讲清楚
```
示例：专注企业数字营销10年，服务客户覆盖零售、教育、金融行业。
      免费提供账户诊断报告，找出你现在在浪费的每一分预算。
```

### 角度2：消除顾虑（2条）
回答用户「为什么要选你」「有什么风险」
```
示例：签约前提供详细方案和预期效果，不满意无需付费。
      专属客户经理，7×12小时响应，随时掌握账户动态。
```

## 文案质量自检清单

在提交前检查：

- [ ] 没有重复相同意思的标题（Google 会降低广告强度评分）
- [ ] 至少有1条标题包含核心关键词
- [ ] 没有全大写（Google 不允许）
- [ ] 没有使用「点击」「官网」「最好」等违规词
- [ ] 描述末尾有明确行动召唤
- [ ] URL 路径与落地页内容相关

---

## 常见违规词（会导致广告不通过）

中文广告常见违规：
- `最`/`第一`/`最好`/`最强`（最高级用语，需有资质才能用）
- `官方`/`官网`（需提供验证）
- `点击`/`点这里`（诱导点击）
- 竞品品牌名（一般情况下不能在文案中用）

---

## A/B 测试建议

每个广告组保持2种文案风格对比：
- 版本A：理性/数据驱动（强调效果、数字、证明）
- 版本B：情感/场景驱动（描述问题场景、用户痛点）

跑满2周、>100次展现后再判断哪个效果更好。
